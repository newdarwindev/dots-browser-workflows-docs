# Public documentation site

Only newly authored public marketing and architecture summary belongs in this repository. Do not copy the private implementation source, profiles, credentials, test logs or artifacts here.

Open `index.html` to preview locally. After creating a **public documentation-only** GitHub repository, push this folder as its root, enable Pages using GitHub Actions in repository settings, and verify the published URL. The workflow uses standard GitHub-hosted runners. No cross-repository publishing credential is needed.
