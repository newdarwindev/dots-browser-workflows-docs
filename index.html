Open architecture · early development

An authenticated browser with a human in control.

A local-first foundation for persistent per-account browsers, agent tasks, and explicit human handoff. Built around durable orchestration and narrow control boundaries.

Selected stack

Clear roles at each boundary.

Browser API

PinchTab

Tabs, actions, snapshots and CDP attachment. A pinned upstream revision is under local integration testing; its attached bridge does not provide scoped sessions.

Visible browser

KasmVNC

A visual stream for the same headed Chromium. The gateway must revoke active streams when control changes.

Secrets

OpenBao

Planned KV v2 credentials, workload identity and Transit envelope keys. The product stores references and sanitized metadata.

Orchestration

Temporal

Workflow state, approval waits and retry policy. Browser-side fencing still belongs to the broker and gateway.

Identity

Authelia + Pomerium

Proposed complementary roles: OIDC/MFA identity provider and identity-aware route proxy. Named interoperability remains untested.

Optional ingress

Caddy

An outer TLS/general-ingress adapter when hosting needs justify it; no duplicate authentication chain.

Control flow

Every handoff has an owner.

01

Identify

Verify the person and their account permission at the gateway.

02

Reserve

Acquire an account lease and restore only its authorized profile.

03

Operate

Route bounded agent commands through the broker to PinchTab.

04

Hand off

Fence old input, close live streams, and grant a fresh human or agent epoch.

Honest progress

What has actually run.

Implemented and tested locally

  • Synthetic unit tests for lease epochs, origin checks, restart-stable intent and connection registry.
  • A local Temporal SDK test server completed a synthetic task and inspected history for a canary.
  • A synthetic Kasm Chromium fixture passed a narrow same-browser check: PinchTab tab ID, CDP target ID, snapshot marker and visible focused page matched after a local patch.

Still being built and verified

  • Production PinchTab/KasmVNC lifecycle, live stream revocation, and durable broker fencing.
  • OpenBao, profile storage, OIDC/MFA integration and full scenario harness.
  • No real website accounts, customer outcomes or production deployment are claimed.
